# 策略成品：V10 Guardrail（引擎护栏 · Generalized 版）

> **一句话定位**：LLM 负责"该不该买、买多少"，引擎负责"破位必须走、弱市不许重仓"——币种无关、周期无关的结构化护栏策略。
> 本文件是 v10 实验的**正式化交付**：规则、默认参数、实证依据、已知边界、自测入口全部在此。
> 版本：2026-09-04 ｜ 配套代码：`main.py`（v10 CLI 开关已内置）｜ 回测证据：见 `baseline_trend/runs/v10_live_ab_verdict.md`

---

## 0. 设计原则（为什么长这样）

实验四窗实跑 + 五次证伪沉淀出的三条铁律：

1. **一切为了收益、降低风险**（目标函数）：护栏是手段，不能反过来牺牲收益。
2. **LLM 的盈利来自"逆势抄反弹"，亏损也来自同款动作**——形态上不可分，任何事前"看形态禁交易"的闸门都会误伤盈利（slope / reentry / EMA纠缠禁交易 / 只做多头排列，四连证伪）。
3. **引擎只做事后护栏，不做事前判断**：结构止损（破位强平）跨市况保护回撤；降杠杆（弱市禁重仓）兑现"允许小试探、规避大量建仓"。判断权留在 LLM。

## 1. 规则定义（三条护栏）

判据锚点：**EMA_SLOW（默认 EMA50）** = 趋势方向基准线（与宪法/规则引擎同源，非新增概念）。

| # | 护栏 | 触发条件 | 动作 | 默认 | 实证状态 |
|---|---|---|---|---|---|
| ① | **结构止损**（rl1） | 持仓中**收盘价 < EMA50**（breach 模式） | 引擎强制平仓，次根开盘离场 | **开**（breach） | ✅ 实跑验证（ETH +1.63pp / 跨窗回撤不恶化） |
| ①c | **离场冷却**（cool） | 红线①离场后 | 冷却期内**禁 BUY**（堵"砍了立刻接刀"） | **20 根** | ✅ 实跑验证配置 |
| ② | **弱市降杠杆**（rl2） | 决策为 BUY 且**收盘 < EMA50** | 杠杆强制 **1x**（只许试探、禁止重仓抄底） | **开** | ⚠️ 单独无效（SOL 实跑证伪），作为①的补充保留 |

**不启用**（已证伪，勿重试）：
- rl1 `dd` 模式（浮亏≥阈值且破线才走）→ 滞后砍深坑 + 接刀反噬
- rl2-only（不加强平）→ SOL 实跑 -5.03%，判据管不到亏损主力（反弹段追高）
- 任何事前形态闸门（纠缠禁交易 / 只做多头 / slope / reentry）→ 误伤震荡市 alpha

## 2. 实证依据（四窗实跑，非离线推算）

全部为 **LLM 档真跑**（烧 API 实跑，非重放）。原 LLM = v9 无护栏；V-C = ①②③全开。

| 市况窗 | 原 LLM | V-C 实跑 | 收益差 | 回撤差 | 读法 |
|---|---|---|---|---|---|
| 牛市 SOL | +3.22% / -1.40% | 0 触发（逻辑闭环） | 0 | 0 | **赚钱时完全不管** |
| 熊市 ETH | -3.60% / -4.13% | **-1.97% / -3.30%** | **+1.63pp** | +0.83pp | 滞后止损型 → 护栏兑现 |
| 熊市 SOL | -5.14% / -5.18% | -4.71% / -4.79% | +0.43pp | +0.39pp | 越砍越勇型 → 被守恒回收 |
| 震荡 SOL | +0.49% / -3.81% | -1.20% / -1.53% | -1.69pp | **+2.28pp** | 护栏保费（回撤减半） |

**跨窗结论**：
- 回撤保护**无一窗恶化** → 护栏的"保险"价值跨市况稳健
- 收益影响**市况依赖**：ETH 型净赚、SOL 型≈0、震荡市付保费
- **决定性变量不是币种，是原 LLM 的止损画像**（滞后止损型 vs 越砍越勇型）——换币/换窗口效果请自行实跑，离线不可外推

## 3. 已知边界（必须知道的代价）

1. **震荡市保费**：EMA50 判据分不清"熊市破位"与"震荡回踩"，弱市区的抄底可能被误压杠杆/误平仓（C 窗实测 -1.69pp 收益换 +2.28pp 回撤）。
2. **反弹段追高盲区**：熊市里价格**站回 EMA50 上方**的反弹段高杠杆追高，护栏管不到（SOL 最深亏 -1723 即此类）。这是判据的结构性盲区，无引擎层解法。
3. **状态分叉**：护栏改变 LLM 观察状态（持仓/权益/仓位）→ LLM 可能用新行为回收护栏省下的风险预算（SOL 熊实测回收 ≈100%）。**离线重放不可信，效果只能实跑验证。**

## 4. 自测入口（你来跑回测）

### 4.1 单命令回测（main.py，推荐）

```bash
cd llm_trading_agent

# 规则引擎档（零 API，先看护栏对机械规则的效果，秒级出报告）
.venv/Scripts/python.exe main.py --mode backtest \
    --symbol BTCUSDT --interval 1d \
    --start 2021-10-01 --end 2022-12-31 \
    --v10-rl1 breach --v10-rl1-cool 20 --v10-rl2

# LLM 档（烧 API：每根 K 线 1 次调用；⚠️ 区间根数 × 1 API）
.venv/Scripts/python.exe main.py --mode backtest \
    --symbol ETHUSDT --interval 1d \
    --start 2021-10-01 --end 2022-12-31 \
    --use-llm \
    --v10-rl1 breach --v10-rl1-cool 20 --v10-rl2
```

参数速查：

| CLI 参数 | 含义 | 默认 |
|---|---|---|
| `--symbol XXUSDT` | 交易对（任意 Binance 对） | .env SYMBOL |
| `--interval 4h/1d/...` | K 线周期 | .env INTERVAL |
| `--start / --end` | 回测区间 YYYY-MM-DD | .env |
| `--v10-rl1 breach` | 红线①结构止损 | 关 |
| `--v10-rl1-cool 20` | ①离场后禁 BUY 20 根 | 0（不冷却）|
| `--v10-rl2` | 红线②弱市降杠杆 1x | 关 |
| `--use-llm` | 真 LLM 决策（否则规则引擎） | 关 |
| `--plot` | 绘权益曲线 PNG | 关 |

> ⚠️ 参数只对 `--mode backtest` 生效；live 档忽略，防止污染实盘 state.json。
> ⚠️ 回测区间需 > 60 根（EMA50 预热），否则引擎报"数据不足"退出。

### 4.2 .env 固化（不想每次敲 CLI）

在 `.env` 打开（`CLI --v10-*` 传入时优先于 .env）：

```ini
V10_ENABLED=true
V10_RL1_MODE=breach
V10_RL1_COOL=20
V10_RL2=true
```

之后 `python main.py --mode backtest` 即默认带护栏；CLI 参数可临时覆盖。

### 4.3 一键 A/B 对照（推荐：护栏 on/off 各跑一次，自动出对照表）

```bash
# 规则引擎档（零 API，确定性，先看护栏的机械边际效应）
.venv/Scripts/python.exe run_strategy_ab.py --symbol BTCUSDT \
    --interval 1d --start 2021-10-01 --end 2022-12-31

# LLM 档（烧 API：2 × 区间根数 次调用，护栏真实效果以此为准）
.venv/Scripts/python.exe run_strategy_ab.py --symbol ETHUSDT \
    --interval 1d --start 2021-10-01 --end 2022-12-31 --use-llm
```

护栏腿固定为实跑验证配置（breach + cool20 + rl2），产物自动存档：
`runs/ab_{tag}_{SYM}_{区间}_{baseline|v10}_report.md`，控制台直接出
总收益/回撤/Calmar/夏普/胜率/PF 对照表。

> ⚠️ **规则引擎档 Δ 因窗而异**：护栏与规则引擎既有风控重叠时 Δ=0（ETH 2022-06~12 短窗），
> 补上规则引擎漏走时段时 Δ≠0（BTC 2022 熊市实测收益 +2.48pp / 回撤 +1.04pp / 少 11 笔）。
> 规则引擎档可作链路验证 + 机械边际参考，但**真实判决必须 `--use-llm`**（状态分叉不可离线外推）。

## 5. 落地建议（回测满意后怎么接实盘）

1. **回测验收**：main.py 的 v10 开关与回测共用同一 `run_backtest` 引擎，可用 CLI（§4.1）或 `.env`（§4.2）固化。
2. **实盘（live 档）**：live 模式暂未透传 v10 护栏（v10 目前为 backtest 档能力）——因红线冷却需跨切片状态持久化，直接接入有状态污染风险。落地实盘前需先完成 live 档透传 + state.json 持久化冷却计数，再 Paper Trading 观察 ≥ 1 个完整牛熊/震荡循环。
