# 2026-09-05 确认式逐级仓位实验记录

## 目标

在现货、无杠杆、long/flat 前提下，测试“10%试探仓 → 25% → 50% → 75%”能否比固定10%仓位更好地抓住主升浪，同时控制熊市、震荡市回撤与交易磨损。本轮全部使用内置规则引擎，未调用 LLM。

## 修改了什么

- `spot_policy.py`
  - 新增实验模式 `SPOT_SIZING_MODE=confirmed`。
  - 空仓只有原策略 `BUY` 才建立10%试探仓。
  - 加仓不读取 LLM 信心；要求盈利、EMA50上升、快线在EMA50上方、MACD多头、至少1 ATR盈利和至少2根K线间隔。
  - 25%→50%还要求突破前20根K线高点；50%→75%还要求近期回踩快线后重新突破。
  - 连续两根跌破快线且MACD柱减弱时降一级；连续两根跌破EMA50时降至试探仓；跌破前10根低点或EMA50下方1 ATR时清仓。
  - 原策略 `CLOSE` 仍可清仓；泛化的 RSI 过热 `SELL` 不再抢先破坏结构完好的主升浪，由机械结构规则负责减仓。
  - 目标仓位受结构止损距离和 `SPOT_RISK_BUDGET_PERCENT` 限制。
- `data_fetcher.py`
  - 新增只使用当前及历史数据的结构列：前值EMA、前值MACD柱、前一根高点、前20根高点、前10/5根低点；无未来数据。
- `main.py`
  - 把完整当前K线传入现货仓位引擎。
  - 报告新增确认式各级加仓、减仓、退出、风险预算压缩和阻断原因统计。
- `order_executor.py`
  - 持仓记录最近加仓K线序号；新增确认式实验统计字段。
- 新增 `_probe_v16_confirmed.py`：覆盖试探、三级加仓、间隔、亏损禁加、三级退出、风险预算、无杠杆/无做空/无funding/无强平。
- 新增 `run_spot_confirmed_ab.py`：固定10%与确认式仓位的确定性零LLM A/B，并支持2%/5%风险预算和关闭移动止盈的独立诊断。
- `.env.example`、`README.md` 增加实验参数说明。

## 没有修改什么

- 没有把 `.env` 的默认仓位模式切换为 `confirmed`；仍为 `SPOT_SIZING_MODE=confidence`。
- 没有开启回测 LLM；`.env` 仍为 `BACKTEST_USE_LLM=false`。
- 没有修改 API key、provider、模型或端点，没有产生付费调用。
- 没有发送真实订单，也没有修改 `state.json` 作为实验输入。
- 没有删除或改写旧 futures 路径、旧报告和旧回测工具。
- 没有修改现有止损、移动止盈（激活2%、从高点回撤5%）、交易费、滑点、账户回撤闸门等默认参数。
- 没有初始化 Git。

## 多窗口零LLM结果

所有窗口均为日线、现货1x、同一规则引擎、固定10%作为对照。表中“收益/DD”为总收益率/最大回撤。

| 窗口 | 固定10% | confirmed，风险2% | 收益差 | confirmed，风险5% | 收益差 |
|---|---:|---:|---:|---:|---:|
| BTC 2023-01-01→2023-06-30 | +1.79% / -0.86% | +2.12% / -0.98% | +0.33pp | +1.47% / -1.50% | -0.32pp |
| BTC 2021-10-01→2022-12-31 | -4.69% / -4.79% | -6.20% / -6.30% | -1.51pp | -7.24% / -7.57% | -2.55pp |
| SOL 2023-01-01→2023-09-30 | +0.73% / -2.63% | +0.65% / -2.37% | -0.08pp | +0.49% / -3.86% | -0.24pp |
| SOL 2024-08-01→2025-01-18 | +2.08% / -1.39% | +1.02% / -1.54% | -1.06pp | +0.18% / -2.76% | -1.90pp |
| 四窗平均差 | — | — | 收益 -0.58pp；DD恶化0.38pp | — | 收益 -1.25pp；DD恶化1.51pp |

观察：

- 2%风险预算仅在1/4窗口提高收益；5%风险预算在4/4窗口都更差。
- 5%风险预算能够触发25%仓位，但增加了熊市/震荡市下行捕获、最差5%行情仓位、换手和成本。
- 所有窗口都没有触发50%或75%仓位。25%→50%的主要阻断是未满足前20根高点突破；因此本轮并未实际验证高仓位能否抓住完整主升浪。
- BTC上涨窗关闭移动止盈后，5%风险预算 confirmed 从“移动止盈开启”的 +1.47% / -1.50% 变为 +0.39% / -2.22%。移动止盈没有压制本轮加仓，反而明显保护收益和回撤，故保持原参数。
- BTC上涨窗买入持有为 +23.61%，SOL上涨窗买入持有为 +63.40%；固定10%和confirmed都只捕获很小一部分，主瓶颈仍是入场/持有路径，而不是最大仓位上限。

## 结论与采用状态

**不采用 confirmed 作为默认策略。** 当前证据不支持逐级加仓优于固定10%安全基线；尤其5%风险预算明显放大熊市与SOL窗口损失。实验代码保留，便于后续研究，但默认配置不切换。

下一轮若继续，应先研究“趋势状态识别 + 允许盈利仓更久持有”，并使用独立训练/验证窗口；不建议继续放宽风险预算或直接降低20日突破门槛来追求回测内加仓次数。LLM可用于解释和候选参数生成，但仓位与退出仍应由固定、可复现规则控制，且任何参数选择必须做样本外验证。
