# 2026-09-05 第三阶段：现货优先与信心仓位验证

本阶段目标：先放弃合约复杂度，只研究现货 long/flat；允许小仓试探，以信心控制仓位，并用收益、回撤、主升捕获、大跌暴露和震荡磨损共同评价。

## 已修改

### 1. 现货执行模式

- `config.py` / `.env` 新增并启用 `TRADING_MODE=spot`；旧 `futures` 路径保留用于复现历史结果。
- spot 模式强制 1x、禁止做空、跳过永续 funding 下载与计提、跳过强平检查。
- 现货手续费默认按 taker 0.10%/边，滑点仍为2bps/边；不套用合约0.04%费率。
- 现货仓位上限按实时市值/实时权益计算，默认75%；不是按历史买入成本或合约保证金计算。
- 修正现货减仓比例：按当前市值计算减仓份额，避免上涨后使用旧成本名义额造成减仓过多。
- 状态文件新增 `trading_mode`；存在持仓时拒绝把 futures 状态加载进 spot（反之亦然）。

### 2. 信心到仓位的引擎映射

- 新增 `spot_policy.py`，模型不再自行决定杠杆或任意仓位。
- 低信心 BUY：HOLD。
- 中/高信心首次 BUY：只建立10%试探仓。
- 加仓必须同时满足：当前价高于持仓均价、价格不低于 EMA50、MACD DIF>DEA。
- 中信心确认后目标上限25%；高信心按 10→25→50→75% 每次只上一级。
- 仓位变化不足5个百分点不成交，降低震荡反复磨损。
- SELL：低/中信心分别减少10/25个百分点；高信心 SELL 全清；空仓 SELL 不开空。
- 旧合约的高乖离保证金衰减不再对 spot 二次缩仓。

### 3. Prompt 与报告

- 新增专用现货宪法：明确 long/flat、无杠杆、无 funding、仓位由引擎映射；旧 v8/v9 合约宪法保留。
- 回测报告新增：买入持有收益、相对买入持有超额、上涨/下跌K线捕获率、最差5% K线平均仓位、累计换手和成本磨损。
- repro 新增交易模式、仓位模式、现货参数和护栏后最终决策。
- 修正 spot 报告页脚，不再显示“固定 funding ?”。
- `force_close` 的成交记录改为退出名义额，而不是错误记录已实现盈亏，换手率才可审计。

### 4. 实验工具和安全设置

- 新增 `run_spot_sizing_ab.py`：信心仓位 vs 固定仓位，支持5轮重复和交替顺序。
- 新增 `replay_spot_counterfactual.py`：把已经保存的同一组 LLM 原始决策离线送入固定仓位执行器，不产生新 API 费用。
- `.env` 将 `BACKTEST_USE_LLM=true` 改为 `false`；以后必须显式传 `--use-llm` 才会产生付费调用。
- `.env` 账户级最大回撤停机线从25%改为15%，与已审查的默认值一致。
- 新增 `_probe_v15_spot.py`；旧 v12-v14 探针显式固定为 futures，防止现货默认值改变旧测试语义。
- README 与 `.env.example` 已更新现货模式说明。

## 验证结果

### 机制测试

- 语法检查：通过。
- `_probe_v12.py`：22/22。
- `_probe_v13.py`：16/16。
- `_probe_v14.py`：11/11。
- `_probe_v15_spot.py`：13/13。

### 零 LLM，BTC 2023-02-18 至 2023-06-29（132根日线）

- 信心仓位：+1.79%，最大回撤 -0.86%，全时段平均敞口1.24%。
- 匹配固定仓位10.26%：+1.84%，最大回撤 -0.88%，平均敞口1.28%。
- 信心仓位收益差 -0.05pp；规则引擎从未满足确认加仓，说明该窗主要瓶颈是信号/持有，而不是仓位映射。
- 买入持有同期 +23.61%；现有规则明显漏掉大部分上涨。
- spot 上直接叠加 v10：收益由 +1.79% 降到 +0.38%，回撤均为 -0.86%；不支持把 v10 直接设为现货默认护栏。

### 付费 LLM 闭环 A/B（temperature=0，每腿5次）

- 实际调用1,275次：信心腿每轮128次，固定腿每轮127次；API错误0。
- 10份 repro 的 OHLCV SHA-256 一致：`059ec6fcc0ab34fa8ebfc3b2c43f0f2fdd40a2ae14b4837efd68904731eb6e75`。
- 1,275条记录全部包含护栏后最终决策。
- 五轮信心仓位均为：收益 +2.07%，最大回撤 -3.09%，平均敞口11.51%。
- 五轮固定10.26%仓位均为：收益 +2.06%，最大回撤 -1.89%，平均敞口7.06%。
- 闭环差：仅多 +0.01pp 收益，但回撤恶化1.20pp、平均敞口增加4.45pp。
- 注意：两腿账户状态反馈给 LLM 后，方向信号会分叉，所以该闭环结果不能称为严格的“同信号仓位归因”。

### 同一信号流离线反事实（零新增 API）

- 使用每轮信心腿保存的原始 LLM 决策，在固定10.26%仓位执行器中按相同时间戳重放。
- 固定仓位收益为 +2.06% 或 +2.72%；信心仓位均为 +2.07%。
- 信心减固定的收益差均值/中位数/标准差：-0.386 / -0.650 / 0.323pp。
- 信心仓位最大回撤始终 -3.09%，固定仓位 -1.89%；信心仓位平均敞口11.51%，固定6.61%–7.06%。
- 当前窗口不支持“信心分仓优于简单固定仓位”；多承担的敞口和回撤没有转化为足够收益。

## 当前结论与下一步

1. spot 架构和信心仓位机制可用，但“信心仓位更优”尚未成立；应视为实验策略，不视为胜出版本。
2. 当前更大的问题是主升浪捕获不足。下一阶段应先诊断 LLM 为什么在上涨窗中退出/空仓，而不是继续扩大高信心仓位。
3. 在未参与本轮设计的 BTC/ETH/SOL 牛市、熊市、震荡窗口上验证；每个窗口同时报告买入持有、固定仓位和信心仓位。
4. 只有信心仓位在同等敞口下稳定提高收益，且没有恶化大跌暴露，才考虑作为默认仓位逻辑。
