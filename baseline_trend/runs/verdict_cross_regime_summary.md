# LLM 增量判决·跨市况汇总（#49 + 候选②熊市复验）

- 判决目标函数：**肥尾 + 有界回撤**（Calmar / PF 优先，回撤预算 ~15%）
- 三腿：L_BASELINE=冻结基线(risk2%) / L_RULES=主项目规则引擎(engine档) / L_LLM=真LLM(llm档)
- 口径：三腿同窗/同成本(taker0.04%+滑点2bp)/同 next_open/同账本；1D K线
- 生成：`verdict_llm_vs_baseline.py`（已参数化支持任意窗口），报告 runs/verdict_report_*.md

## 判决：牛熊不对称——两条腿各司其职，双轨架构被实证支持

**1) 熊市防守排序：L_RULES ≥ L_LLM >> L_BASELINE（全亏市况下谁亏得少）**
- ETH 熊：规则 -1.39%（DD -3.33%）≈ LLM -3.60%（DD -4.13%）的 2.6 倍抗跌；基线 -17.66%（DD -18.35%）灾难。
- **冻结基线在熊市回撤 -18.35% 超 15% 预算 → 不可单独用于实盘**（原 v3 的 EMA200 禁入正是为此而生）。

**2) 牛市进攻排序：L_LLM >> L_RULES（#49 复看）**
- 规则引擎牛市竟亏 -0.70%（20 回合高换手磨损、PF 0.40 三腿最低），LLM +3.22% 且 DD -1.40% 全场最优。
- 机械基线牛市 +4.83% 但 DD -9.86% 接近预算上限；v3 升级(10%)后收益 +19.30% 但 DD -29.61% 超预算。

**3) 合成结论（回撤预算 15%）**
- **LLM 腿保留**——牛市进攻不可替代（Calmar 2.30 vs 规则 -0.26），熊市 DD 亦在预算内（-4~-5%）。
- **引擎宪法红线层必须保留**——熊市 LLM(-5.14%/-3.60%) 不如规则引擎(-3.29%/-1.39%)果断
  （LLM 倾向等反弹拖累止损），规则机械止损恰好补上；这正支撑主项目 **v9 双轨：LLM 判断 + 引擎宪法兜底**。
- **冻结基线只配当参照系/阈值基线**，配 v3 EMA200 禁入后才有预算安全性；实盘主执行走规则/LLM 腿。

## 审计与成本

- 两熊市窗 LLM 腿共 ~776 次 API（回放 408 根/窗 ≈ 388 次/窗，逐根调用），耗时 ~9min/窗。
- 成本教训：窗口回放根数 ≠ 直觉（全年窗含预热起点 2021-11-18，比"2022 全年"多 6 周），
  烧 API 前必须先跑零 API 规则腿读取实际回放起点/根数，再向用户摊牌成本。

## 遗留

- 单窗牛市 + 双窗熊市 = 3 窗样本；如需更高置信可补震荡市窗（LLM vs 规则在横盘的取舍）。
- LLM 熊市止损不够果断的具体诱因（prompt 层"等反弹"倾向 vs 引擎层）可作为 v10 优化方向，
  目标：把 LLM 熊市亏损从 -3.6~-5.1% 压到规则引擎的 -1.4~-3.3% 区间。
