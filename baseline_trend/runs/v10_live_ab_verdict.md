## 二、判决结论（v10 定位 = 回撤保险，不是收益增强）

1. **回撤保护跨市况稳健（三窗全改善或持平）**：SOL 熊 +0.39pp、ETH 熊 +0.83pp、震荡 +2.28pp、牛市 0。红线把"LLM 深亏仓"前置砍成小亏，**最大回撤无一窗恶化**。（注：这是 V-C 全套含"结构止损"的成绩；**仅降杠杆的 rl2-only 在 SOL 熊市回撤反恶化 -0.46pp**，见三-A。）
2. **收益影响高度市况依赖（不可离线预测）**：牛市 0 成本、ETH 熊 +1.63pp、SOL 熊 ≈0、震荡 -1.69pp（保费）。
3. **定论（修订）：有效成分是红线①结构止损，不是降杠杆**。V-C 的跨窗回撤保护与 ETH +1.63pp 主要来自"破 EMA50 强平深亏仓"；rl2-only 实测证明纯降杠杆在熊市收益≈0 且回撤恶化。若目标只是"熊市不大仓"（用户诉求），EMA50 判据无法覆盖**反弹段追高**（深亏主力），需先解决判据问题。
4. **落地建议（修订）**：若要落地，配置应为 **V-C（rl1=breach + cool20 + rl2）而非 rl2-only**；且需接受震荡市保费。纯 rl2-only 已实证不可行。

## 三-A、SOL 熊市 rl2-only 实跑归因（用户目标形态的直接检验）

**背景**：用户目标 = "熊市规避大量建仓、允许小量试探"。rl2-only（只降杠杆 cap 1x，不砍仓、不禁买）正是该目标的直接实现。离线预测 -2.62%（改善 2.52pp），实跑 **-5.03% / -5.64%**——收益仅 +0.11pp（≈0），**回撤反而恶化 0.46pp**。第三次离线翻转。

**逐笔归因（为何降杠杆救不了熊市）**：

| 类别 | 明细 | 结论 |
|---|---|---|
| 降杠杆"触发率虚高" | 红线②触发 9 次，但 10 笔 BUY 里仅 4 笔真被压到 1x（12-24/03-17/06-07/10-26，全在 EMA50 下方接刀处） | 判据盲区：**EMA50 上方的追高 BUY 从不被压** |
| 最大亏损单未被拦 | 全窗最深亏 -1723（09-13 3x 追高 @37.44 → 09-14 -11.86%）：**当日收盘在 EMA50 上方** → rl2 不触发 | 熊市反弹段的高杠杆追高恰恰是最大亏损源 |
| 被压的小仓也错失反弹 | 07-19/07-29 两笔 3x 抄底（EMA50 上方，未压）实为 07-21/08-03 亏损主力 | 降杠杆只作用于"接刀区"，而接刀区本就轻仓试探 |

**机制**：rl2-only 只约束"EMA50 下方的 BUY"，但 SOL 熊市里 LLM 的深亏主要来自**反弹段（价格站回 EMA50 上方）高杠杆追高**——r值被误认为反转。降杠杆作用域与实际亏损源错配；且压杠杆后 LLM 观察状态（浮盈/仓位）改变 → 状态分叉再次吃掉离线收益。

**结论**：rl2-only 单独落地**不成立**（收益≈0 且回撤恶化）。用户要的"熊市不大仓"必须覆盖**反弹段追高**，而 EMA50 判据无法区分"熊市反弹"与"真反转"（与 slope/reentry 闸门证伪同一根源）。

### 11-03 状态分叉完整链条（教科书案例）
```
10-05 BUY @1361.5（两腿同价开仓）
 ├─ 原 LLM：3x 持有，未受引擎干预 → 11-03 移动止盈 @1518.3 → +1000.7 (+11.5%)
```

**为何 ETH 兑现而 SOL 翻转？** 决定性变量 = 原 LLM 画像。ETH 原 LLM 是"滞后止损深亏型"（6 笔 >500 深亏、平均扛到 -10% 才走），红线前置拦截的单笔价值巨大且被 LLM 状态分叉回收的比例较低；SOL 原 LLM 砍仓后反弹博弈更激进，红线省下的 ~2354 几乎全被新错误回收（净 -37≈0）。**红线对"砍了就认、不急着加倍回补"的 LLM 有效，对"砍了立刻更高杠杆抄回"的 LLM 会被风险预算守恒抵消。**

## 五、落地配置与待拍板点

**修订结论**：rl2-only（用户目标"只降杠杆许试探"的直接形态）已在 SOL 熊市实跑证伪（+0.11pp 收益 / 回撤反恶化），**不应单独落地**。若落地 v10，须含红线①结构止损（V-C = `rl1_mode=breach, rl1_cool=20, rl2=True`）——跨窗回撤保护与 ETH +1.63pp 的真正来源。

**但需直面用户目标与数据的错配**：用户要"熊市规避大量建仓、允许小量试探"。实跑显示：
- 深亏主力是**熊市反弹段（EMA50 上方）高杠杆追高**，不是 EMA50 下方接刀 → EMA50 判据抓不到真正的"大量建仓"；
- V-C 的回撤保险**跨市况稳健**（含震荡市腰斩回撤），但收益在震荡市负贡献（保费 -1.69pp）；
- 用户原则"一切为获取收益、降低风险" → **保费换回撤**是否可接受需拍板。

**拍板点**：
- **选项 A**：接受 V-C 为资金护栏落地（回撤保护三窗稳健 + ETH +1.63pp），接受震荡市保费与"救不了反弹段追高"的判据局限。
- **选项 B**：先解决判据问题——把降杠杆/强平的触发从"EMA50 下方"扩到"熊市反弹段追高识别"（需新判别思路，slope/reentry 已证伪，工作量大），再实跑验证。
- **选项 C**：不落地 v10，维持 v9——放弃 ETH +1.63pp 与全部回撤保险，也省掉震荡市保费与 API 消耗。

**作者倾向（更新）**：若以"收益/风险"为唯一裁判且不愿意为保险付震荡市保费，则 **A 需用户确认接受保费**、C 是风险中性者的理性选择。v10 不是"免费的收益午餐"——它是一份保费不确定的保险，且救不了用户真正担心的"熊市反弹追高大仓"。

## 附-A：EMA 纠缠闸门假设检验（2026-09-04 用户提议，零 API 分桶归因）

**用户假设**："几条 EMA 纠缠时不去交易，出现较明显趋势再交易"（规避震荡假信号）。

**检验方法**：给四窗原 LLM 实跑日志每笔 BUY 标注开仓决策时刻 EMA6/20/50 形态（新算 ema20 中轨），分桶累计盈亏：

| 窗口 | 多头排列(顺势) | 空头排列(逆势抄底) | 纠缠/交叉 |
|---|---|---|---|
| 牛市 SOL | +1793 | +928 | +235 |
| 熊市 SOL | -704 | **-3217** | -136 |
| 熊市 ETH | -318 | -1072 | -1134 |
| 震荡 SOL | -1483 | **+3283** | -669 |

**反直觉发现**：
1. **LLM 在纠缠期其实亏得不多**（熊市 SOL 仅 -136）——它天然谨慎。真正大亏在"均线明确排列时也敢重仓"：熊市空头排列抄底 -3217 是重灾区。
2. **震荡市最大盈利 +4222（2023-06-22 BUY@17.23）恰是空头排列深水区抄底**——若"纠缠不做 / 只做多头排列"，震荡市会错过神抄底 + 留下多头追高 -1483，从 +1131 变得更差。
3. **根源**：均线形态是滞后描述，分不清"熊市空头排列 = 接刀"与"震荡空头排列 = 黄金坑"，与 slope/reentry 闸门证伪同源。

**结论**：EMA 纠缠禁交易闸门**不落地**。形态判别类事前闸门**四连证伪**（slope / reentry / 纠缠禁交易 / 只做多头排列）→ 事前"该不该在此形态开仓"的判断权应留在 LLM；引擎层有效成分只有事后护栏（红线①结构止损）。
