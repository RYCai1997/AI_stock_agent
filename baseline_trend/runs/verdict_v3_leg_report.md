- 窗口：SOLUSDT 1D，回放 2024-09-18 → 2025-01-18（与 #49 三腿判决**同窗**）
- 目的：回答「冻结基线升级为 v3 甜点位（EMA200 上 10% / 下禁入 / 无账户闸门）后，LLM 是否仍优」

- 生成：`_verdict_v3_leg.py`（已清理），临时对照脚本

## 关键事实

1. **L_V3 ≡ 固定10%**（开仓档位 `{0.1: 3}`，与固定10% 逐位相同）。
2. 本窗（2024-09→2025-01，SOL 单边上行）EMA50 信号全部在 EMA200 上方触发，**EMA200 禁入闸门零拦截** → v3 在本窗退化为纯仓位放大：2%→10%。
3. 仓位放大收益近线性：3 回合 +4.83%（2%）→ +19.30%（10%），≈5×（回合内复利略低）。
4. 回撤同步放大：-9.86% → -29.61%（≈3×，因回撤发生在较早回合、仓位按当时权益）。

## 判决解读

**Calmar / PF 口径（目标函数「肥尾+有界回撤」）：L_LLM 仍最优，优势稳健。**

- L_LLM Calmar 2.30 = L_V3(0.65) 的 **3.5×**、L_BASELINE(0.49) 的 4.7×。
- L_LLM PF 4.59 = L_V3(2.48) 的 1.9×。
- 即使把冻结基线升级到 v3 甜点位（本窗等价 10% 满仓），LLM 的风险调整优势没有被追平。

**但收益轴必须如实汇报：**

- 机械 10%（=v3 本窗形态）赚 **+19.30%，是 LLM(+3.22%) 的 6×**；代价是回撤 -29.61%，为 LLM(-1.40%) 的 21×。
- 13 回合 LLM 只积累 +3.22% → LLM 在本窗多次上下车，规避了大回撤但也错过了主升浪的大段。
- 含义：**LLM 的真实价值是「下行保护/回撤控制」而非「收益放大」**。Calmar 冠军主要由分母极小（回撤 -1.40%）驱动，不能解读为 LLM 收益生成优于机械。

## 结论与边界

1. **回撤预算决定 LLM 是否「必要」**：
   - 账户可承受 ~30% 回撤 → 机械 v3(10%) 是更优基线，牛市窗口 LLM 不增收益（+3.22% vs +19.30%）。
   - 回撤预算 <5% → LLM 是唯一满足「有界回撤」的腿（-1.40%），机械任何档位都做不到。
2. 单窗结论效力有限：本窗是单边牛市，LLM 的防御价值在熊市窗口才能充分体现 → **候选②（烧 API 多窗口复验，含熊市窗）是唯一能判定 LLM 存废的下一步**。
3. 盲区验证（`regime_transition_check.md`）已证明 v3 禁入在真实崩盘底零拦截——本窗零拦截与之一致，属预期而非缺陷。
