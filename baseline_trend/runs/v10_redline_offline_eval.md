## 三条核心发现

### ① 牛市零误伤不是运气，是结构性
dd5 与 breach 两模式牛市窗均 **0 触发**（持仓浮亏从未 ≥5%，收盘也从未 <EMA50）。LLM 牛市只在 EMA50 上方做多、
持仓中价格始终站趋势线上方 → "收盘<EMA50 即走"红线在牛市是空转的保险丝，只有熊市持仓才会触发。**这使红线①可以无脑启用。**

### ② 初版红线①（浮亏≥5% AND 破线）被证伪：滞后 + 接刀
- **滞后砍深坑**：AND 条件里 EMA50 下移滞后于价格（快跌市），触发时浮亏已达 **-5.2~-10.2%**（ETH 5 次触发），
  远深于规则引擎"破线即走"的 -1~-4%。11-22、02-17 两次触发与 LLM 自救完全重合（零提前量）。
- **砍后接刀反噬**：红线砍仓释放资金 → llm 档不拦 EMA50 下方 BUY + 冷却仅 3 根（POST_LOSS_COOLDOWN_BARS）→
  LLM 重新接刀 → **分叉出真跑不存在的 -18.85% 新灾难单**（ETH 2022-11-09），把改善全部吃掉还倒亏
  （ETH rl1dd5 单开 -5.20% < 原 -3.60%）。
- 逐笔对照证据：被红线砍的 4 笔中 3 笔本身合理（07-10 提前 1 天省 5.8pp、03-04 提前省 2.4pp），
  损害全来自砍后分叉再入场。

### ③ 改造版红线① = 破线即走 + 冷却，两个旋钮都必要
- **mode=breach（收盘<EMA50 即走，无浮亏门槛）**：把结构离场从"等浮亏深"改成"破位即走"，
  触发浮亏从 -5~-10% 缩到 **-0.7~-3.8%**（ETH 6 次触发），与规则引擎"趋势线离场"同构。
- **离场冷却禁 BUY（rl1-cool）**：堵接刀。被吞的 BUY 清一色是 LLM"回调低吸/轻仓试多/放量反弹"逆势单
  （如 11-30 @4630 接刀、02-15 @3183 接刀——02-15 正是规则引擎 02-17 小亏离场前 LLM 想抄的底）。
- **冷却长度驼峰曲线**：cool10 磨损残留 → cool20 最优（SOL +0.94 / ETH -1.47）→ cool30 变差
  （SOL -2.32：错过 4 月真反弹）。20 根≈1 个交易日月，语义="破结构位后 1 个月内不逆势"。

### ④ 震荡市误伤实锤：冷却吞主升 > 红线省的小亏（净效应为负）
V-C（breach+cool20+rl2）在震荡窗触发 5 次、净收益 **+0.49% → -2.33%**（-2.8pp）。逐笔对照三重伤害：
- **冷却禁闭错过主升（决定性）**：06-23 红线离场 → 20 根冷却禁 BUY → 真跑同段 07 月初 BUY 吃到
  **07-19 +48.23%（+4221 USDT，全窗最大盈利单）**——V-C 平仓列表该单**完全消失**。熊市里冷却吞的是
  接刀单（负价值），震荡市里跌破 EMA50 后常反转向上，冷却吞的可能是主升单（正价值）。
- **盈利误砍**：09-19 在 **+1.88% 浮盈**时被"收盘<EMA50"强制离场——breach 无浮亏门槛，价格短暂跌破
  EMA50 的正常回调也被当趋势反转砍掉。
- **rl2 cap 掉主升建仓**：06-21 的 3x→1x cap 恰砍在 7 月主升建仓上（价格 17.23<EMA50 但正是底部区），
  收益缩 2/3 → rl2 单独也 -1.95%。
- 红线①也有正贡献（05-07 提前砍 -3.99% vs 真跑同仓 05-09 止损 -9.60%，省 5.6pp），但远抵不过错过的主升。

**设计含义**：EMA50 位置做市况锚区分度不足——牛市持仓全程在其上方、熊市全程下方、震荡市高频穿越，
单锚无法把"熊市破位"与"震荡市假破位"分开。v10 落地需 regime gate：**红线只在更长周期趋势确认下行时启用**
（候选：EMA200 下方 或 EMA50 持续下行 / 斜率过滤），震荡市（价格围绕长锚横向运动）不启用红线①与冷却，
仅保留杠杆约束或全部放行。具体 gate 参数需下一轮离线扫描。

## 局限性与诚实声明

1. **三窗调参过拟合风险**：cool20 是 10/20/30 三点扫描出的最优点，仅 SOL/ETH 两熊市窗验证；
   且震荡市窗（225 根）已证该配置**跨市况不可迁移**——任何参数在单市况调优后必须做四象限（牛/熊/震/）复验，
   缺象限即可能过拟合（本次即教训：熊市最优配置在震荡市倒亏 2.8pp）。
2. **决策流固定假设**：离线重放假设 LLM 决策流不因状态分叉而变。实跑时红线介入改变持仓状态 →
   LLM 收到的 prompt（position/pnl/equity）不同 → 真实决策会偏离 repro。**离线结果是"引擎红线叠加在
   原决策流上"的效果估计，方向可信、幅度需实跑确认。** 尤其冷却吞 BUY 的"被吞单"在实跑中不会发生
   （LLM 看不到这些决策）——实际效果取决于 LLM 在新状态下的真实选择，可能优于也可能劣于估计。
3. 牛市仅 1 窗（122 根），"牛市 0 误伤"结论需要更多牛市窗佐证；震荡市仅 1 窗，误伤幅度需更多横盘窗复验。
4. 重放器只支持 next_open 执行模型（与 verdict repro 同口径）。

## 推荐 v10 落地配置（修订版：带市况闸门）

**教训：红线不能无脑全局启用。** 牛/熊/震三态实测为 0 触发 / 大幅改善 / 严重误伤，落地配置如下：

| 项 | 值 | 语义 |
|---|---|---|
| **市况闸门（新增，先决条件）** | 更长周期趋势锚（候选 EMA200 或 EMA50 斜率）判定下行趋势时红线才武装 | 牛市/震荡市红线不武装 → 不误伤；熊市红线武装 → 止损前置 |
| 红线① | 闸门开启时：持仓中**收盘 < EMA_SLOW → 引擎强制平**（次根开盘离场），无浮亏门槛 | 规则引擎"破趋势线即离场"搬给 LLM 档共用，仅熊市生效 |
| 红线①冷却 | 红线①离场后 **20 根禁 BUY** | 熊市破结构位后 1 个月内不逆势接刀 |
| 红线② | 闸门开启时：**收盘 < EMA_SLOW 的 BUY → 杠杆 cap 1x** | 熊市持仓不放大，牛市/震荡市放行不受限 |
| 落地位置 | 全部在 `order_executor` / 引擎循环层（红线不进 prompt，不改变 LLM 决策空间）| v9 架构哲学自洽：宪法红线引擎兜底 |

预期效果（离线估计）：熊市窗口 LLM 亏损从 -3.6~-5.1% 压到 **-1.5%~+0.9%**（对齐或超越规则引擎），
牛市进攻性（Calmar 2.30）不受影响，震荡市不启用红线保持原 LLM 行为（+0.49%，纪律性由规则档提供）。
