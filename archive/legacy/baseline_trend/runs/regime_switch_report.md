## 结论（v3 收敛 · #48 落地完成）

1. **甜点位 = EMA200 上方 10% / 下方禁入 / 无账户闸门**：9窗 +138.0%（超固定10% +125.3%），
   熊市 -13.8%（vs 固定10% -50.0%，砍 72%），Calmar 均值 4.80 为稳健最高——不靠单窗虚高
   （15% 档 6.89 是被 SOL_牛23 +1285% 单窗拉起的均值幻觉，其震荡窗回撤 -40%+ 失控）。
2. **EMA200 禁入后 25% 账户闸门零增量反减益**：熊市保护已由禁入完成（熊市根本不开仓、不触发闸门）；
   闸门只在牛市中途误伤尾部（SOL_牛23 +726→+350、ETH_牛23 +162→+35）。#48「固定档需要闸门」的结论
   是**无 EMA200 开关前提**下的；状态切换后闸门冗余。
3. **15% 档在震荡/主升浪窗回撤失控**（ETH_主升浪 -41.8%），违反「有界回撤」→ 弃。
4. 已知局限（诚实披露）：9 窗窗口起点价格都在 EMA200 上方（牛市进行中），「熊转牛第一波」
   （价格从 EMA200 下方突破）被禁入漏掉——样本未覆盖该场景，禁入=放弃抄底段，代价未知。
   另主升浪/横盘窗（ETH_主升浪 B&H+1%）回撤仍 -31%：趋势跟随在震荡市磨损是固有属性，
   EMA200 开关只能挡熊市深跌，挡不了「EMA200 上方横盘」。
