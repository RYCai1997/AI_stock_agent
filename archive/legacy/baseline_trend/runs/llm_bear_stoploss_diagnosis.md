# LLM 熊市止损拖累诊断（v10 前置分析）

- 日期：2026-09-03
- 数据源：两熊市窗（SOLUSDT / ETHUSDT，回放 2021-11-18 → 2022-12-31，408 根）已烧的 LLM repro json（SOL 401 条 + ETH 399 条原始响应）与 verdict 日志
- 方法：**零新增 API**。纯读取已存档的逐根 LLM 决策（action/stop_loss_price/reasoning_summary）与平仓流水，对照规则引擎同窗日志
- 目标：解释「LLM 腿熊市亏损（SOL -5.14% / ETH -3.60%）为何深于规则引擎（SOL -3.29% / ETH -1.39%）」，为 v10 优化提供证据

---

## 0. 结论速览（TL;DR）

LLM 腿熊市超额亏损 = **止损语义错位**，三层层叠：

1. **实际刹车在「LLM 自设止损位」，而该位被放到 -20% 深处**（"近期低点下方"）。持仓浮亏时 LLM 的行为是 92~95% 概率的"观望/等待企稳"，CLOSE 只在价格收盘击穿其自设止损后才发生 → 单笔亏损普遍 -7~-20%。
2. **引擎两条机械止损线都没兜住**：
   - 逐仓价格止损线（ATR 放宽，`max(2%, 1.5×ATR)`）：2022 高波动把它推到 -10~-20% 以外，触发即深亏（两窗共 4 次触发，亏损 -9.9~-14.1%），多数深亏单它比 LLM 自设线还远、根本不触发；
   - 组合权益止损（浮亏 ≥ 2% 总权益）：LLM 单仓名义仅 5~15% 权益，需价格反向 13~40% 才够到线 → 两窗 **0 次触发**，只防单仓灾难、不防慢刀子。
3. **杠杆放大**：共享回合中规则引擎 1x、LLM 2~3x → 同信号同价位亏损绝对值约 ×2。

对照：规则引擎的离场刹车型号不同——「价格 < 长周期趋势线（EMA50）→ 当日按宪法离场」，锚定**价格结构**而非**价格距离**，与波动率无关，故能在 -1~-4% 小亏处截断（ETH 三案例提前 1~4 天，省 5.8~11.7 个百分点）。

## 1. 引擎止损架构盘点（代码核实）

两条机械路径 + LLM 自设线，三者语义不同：

| 路径 | 触发条件 | 计数位置 | 两窗触发 | 实际效果 |
|---|---|---|---|---|
| A. 逐仓价格止损线 | 开仓时设 `stop_price = 开仓价×(1−max(2%, 1.5×ATR%))`，收盘价击穿即离场（next_open 次根开盘成交） | **不计入** `止损触发:N` | SOL 1 次 / ETH 3 次 | 高波动期被 ATR 拖到 -10~-20% 外 → 触发即深亏 |
| B. 组合权益止损 | 单仓浮亏 ≥ 2% 总权益 | 计入 `止损触发:N` | SOL 0 / ETH 0 | LLM 仓位小（名义 5~15% 权益）够不到 → 从不动 |
| C. LLM 自设止损位 | LLM 决策里报的 `stop_loss_price`（"近期低点下方"） | 无独立计数 | 实际绑定的刹车 | 熊市被放到 -15~-25%，收盘击穿才离场 |

> ⚠️ 报告尾部统计里的 `止损触发: N` **只计路径 B**（order_executor.check_stop_loss → stats["stop_loss"]）。此前 "止损触发:0 = 引擎从不止损" 的表述不准确——路径 A 触发过 4 次但每次都已是深亏。两条机械线共同的问题是**触发太晚**，不是不触发。

**为什么路径 A 追不上**（SOL 06-07 最典型）：开仓 42.39，单日 ATR 极端放大 → 止损线 ≈ 42.39×(1−~20%) ≈ 34 下方；价格阴跌到 33.94 收盘时 LLM 自设线（33.91）也只差 3 分钱。两条 -20% 的"刹车"同时失效 → 该笔 -19.93%（-1,778 USDT），全窗最深。

## 2. LLM 逐笔行为证据

### 2.1 持仓中 HOLD = 观望/等待（量化）

从 repro json 用 `stop_loss_price > 0` 判定持仓中（空仓 HOLD 该字段为 0），统计 reasoning_summary 含「观望/等待/企稳/观察/反弹/支撑」类词的占比：

| 窗口 | 持仓中 HOLD 次数 | 观望/等待词占比 | LLM 原始 CLOSE 指令 |
|---|---|---|---|
| SOL | 38 | **92.1%**（35/38） | 3 |
| ETH | 91 | **94.5%**（86/91） | 3 |

微距铁证（SOL 06-08 → 06-11，开仓 42.39 后连跌）：
- 06-08 HOLD："持仓浮亏且止损未触发，观望为主"（自设止损 33.91，距开仓 -20%）
- 06-09 HOLD："持有观察"
- 06-10 HOLD："持有观望等待企稳"
- 06-11 CLOSE："价格跌破止损价且趋势极弱" → 06-12 开盘 33.94 成交，**-19.93%**

LLM 的"持仓纪律"= 盯住自己那条 -20% 的线，线不破就不走。"等企稳/等反弹"在单边阴跌里等价于**让亏损跑到最大**。

### 2.2 亏损单全部深于 -7%，且集中在两种离场方式

**SOL LLM（10 回合，2 胜 8 负，累计 -4,058 USDT）：**

| 平仓日 | 离场方式 | 盈亏 | 说明 |
|---|---|---|---|
| 2021-12-05 | 路径 A 价格线 | -704（-14.09%） | 与规则引擎同日同价，LLM 杠杆 2x 致金额 ×2 |
| 2021-12-29 | LLM CLOSE | -929（-10.40%） | "止损位已破，立即离场" |
| 2022-03-05 | LLM CLOSE | -1,006（-11.38%） | 规则引擎未做该笔逆势抄底 |
| 2022-06-12 | LLM CLOSE | **-1,778（-19.93%）** | 全窗最深，见 2.1 微距 |
| 2022-07-21 | 移动止盈 | -499（-3.42%） | 先小浮盈激活 → 反转砍仓 |
| 2022-08-03 | 移动止盈 | -1,058（-7.32%） | 同上 |
| 2022-09-14 | 移动止盈 | -416（-4.84%） | 同上 |
| 2022-11-03 | 移动止盈 | -17（-0.19%） | — |
| 2022-04-06 / 08-16 | 移动止盈 | +2,097 / +252 | 仅有的 2 胜 |

亏损构成：3 笔 LLM CLOSE 深亏合计 **-3,713 USDT ≈ 占全部亏损 91%**；另加 1 笔路径 A -704 与 5 笔移动止盈小亏。**深亏单（≥-10%）贡献了几乎全部损失。**

**ETH LLM（12 回合，6 胜 6 负，累计 -2,523 USDT）：**
- 6 笔亏损单：-7.39 / **-11.08** / **-9.16** / **-12.65** / **-11.40** / **-9.86**（其中 3 笔路径 A、3 笔 LLM CLOSE）——**无一浅于 -7%**
- 6 笔盈利单平均 +7.0% → 盈亏同源、幅度对称，但熊市里亏损单的深度没有刹车

### 2.3 超长持仓说法修正

逐笔 BUY→平仓 1:1 配对后，两窗所有回合持仓仅 **2~19 天**（此前笔记中"ETH 111 天跨主跌浪"系配对错误，予以作废）。问题不在"拿得久"，而在**拿着的每一天都在观望，直到 -10~-20% 才离场**。

## 3. 规则引擎对照：宪法趋势线离场 = 提前小亏

规则引擎同窗有一套与波动率无关的离场规则——「价格 < 长周期趋势线（EMA50/慢线）→ 当日按宪法离场」。**EMA 趋势线是价格结构锚，不是距离锚**，急跌第一天就破线。

最干净的三个受控对照（ETH，规则引擎与 LLM 几乎同位置开仓）：

| 案例 | 规则引擎 | LLM | 规则引擎提前 | 省下的亏损 |
|---|---|---|---|---|
| 2022-02 崩溃 | 02-17 宪法离场 @3122 **-1.92%** | 02-16 同价开仓 3183，02-18 CLOSE **-9.16%** | 1 天 | **7.2 pp** |
| 2022-03 续跌 | 03-03 宪法离场 @2947 **-0.98%** | 03-07 路径 A 止损 **-12.65%** | 4 天 | **11.7 pp** |
| 2022-12 阴跌 | 12-16 宪法离场 @1266 **-4.10%** | 12-17 路径 A 止损 **-9.86%** | 1 天 | **5.8 pp** |

> 注：02 月案例为同开仓日（02-16 均 @3183.53）的完美受控对比——规则引擎在价格收盘 < EMA50（3127）的当天走，LLM 多看一天，恰好吃到 02-17→02-18 的单日 -7.4% 崩跌腿。
> 代价提示：03-03 案例规则引擎也被"洗"了一次（-0.98%），即趋势线离场在震荡反弹期有磨损成本，但磨损是 -1% 级，换掉的是 -12% 级深亏，不对称性显著有利。

SOL 窗则呈现另一种结构：两腿共享的 6 个回合（12-03 / 12-27 / 03-25 / 07-19 / 07-29 / 08-11 同日期同价开仓）**离场时点几乎完全一致**（同为路径 A/移动止盈机械驱动），差异仅在杠杆——**LLM 2~3x vs 规则引擎 1x，同一笔 -14.09% 规则亏 -352、LLM 亏 -704**。LLM 额外亏损还来自 4 笔规则引擎不做的逆势抄底（03-01 / 06-07 / 09-10 / 10-26，"超跌反弹/轻仓试多"），其中 03-01→-11.38%、06-07→-19.93% 贡献了最重两笔。

> 两窗画像不同但结论同向：**ETH = 止损滞后拖累（LLM 等止损位 vs 引擎破趋势线即走）；SOL = 逆势抄底 + 杠杆放大（LLM 抢反弹、引擎机械过滤不做）**。共同点：引擎级的"结构/纪律"刹车在熊市都比 LLM 的"距离止损 + 观望"更早更小地认亏。

## 4. v10 优化方向（按优先级）

| # | 方案 | 层级 | 机制 | 预期收益 | 风险 |
|---|---|---|---|---|---|
| 1 | **结构止损红线**：持仓浮亏 ≥ -5% **且** 收盘价 < EMA50 慢线 → 引擎强制平仓（不等 LLM、不等 ATR 宽线、不等"止损位已破"） | 引擎红线（宪法级） | 把"结构离场"从规则引擎搬到 LLM 档共用；红线由引擎兜底、不进 prompt（既有铁律） | ETH 三案例类推：单笔深亏 -10~-20% 截到 -5~-8%，熊市窗口收益向规则引擎区间（-1.4~-3.3%）收敛 | 震荡市被洗出（参照规则引擎 -0.98% 磨损）；需校准阈值与「连续观望 ≥N 天」变体 |
| 2 | **熊市降杠杆**：EMA50 下方禁 >1x（与规则引擎对齐），牛市放开 | 引擎红线 | 消除共享回合 ×2 亏损放大；顺带抑制"超跌抄底"吸引力 | SOL 共享回合亏损减半 | 可能削牛市进攻性（需牛市窗回测验证不回吐） |
| 3 | **prompt 弱化"等反弹"**：持仓决策模板加"趋势结构离场"条款，止损位建议从"近期低点下方"改为"收盘 < EMA50 即走" | prompt 层 | 治本于决策源 | 持仓 HOLD 观望 92~95% 占比下降 | 红线不寄望 prompt（历史教训）；LLM 可能复读机化 → 仅作辅助 |

推荐先做 1+2（纯引擎层、可回测、不动 prompt），3 视 1+2 效果再定。
