# 归档区

此目录保存历史研究、旧实现和已完成的计划，仅用于追溯和研究审计，不属于当前 production / official runtime。正式入口不得 import 此目录中的代码。

- `legacy/llm_trading_agent/`：旧LLM和币圈交易实验；
- `legacy/baseline_trend/`：旧纯价格趋势策略；
- `research/stock_selector/`：历史A股节点回顾、组合宽度比较、美股适配及跨市场研究工具；
- `planning/`：已经完成的重构计划。

其中组合宽度比较、风险规则反例、月度退出反例和旧节点结果仍值得研究，但这些离散节点不是连续账户净值，也不是严格样本外验证。归档文件不应生成当前交易信号。根目录未追踪的旧`.env`、虚拟环境、缓存和运行输出没有被移动或纳入版本控制。
