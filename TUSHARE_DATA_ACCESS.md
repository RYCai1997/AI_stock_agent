# Tushare historical-data access and blocked state

**2026-09-30 status: optional, inactive retrospective provider.** Tushare requires credentials and is not used by `PUBLIC_V1`. Missing `TUSHARE_TOKEN` does not block prospective predictions or their tests. This runtime has no token; its direct HTTPS transport has only been exercised by local tests with synthetic responses. No Tushare API permissions, endpoint availability, field definitions, quotas or historical depth have been verified.

`REQUIRED_TUSHARE_ENDPOINTS.json` lists the candidate endpoints and supplemental official sources. Each endpoint requires a live permission probe; a valid token alone may not grant it. In particular, historical index weights, financial tables, daily limits, suspension, distributions and industry history must be checked independently. `stock_selector/data_history/schema/historical_pit_schema.json` defines the standardized local records and fail-closed dating rules. Raw Pro responses belong under ignored local cache storage and retain their SHA-256, request parameters (excluding token), retrieval time, endpoint, row count and unaudited coverage status. The provider never saves the token.

If optional Tushare retrospective research is resumed, set `TUSHARE_TOKEN` in the **process environment** or another secret store that injects it at runtime. Do not put it in a source file, report, issue, chat message or Git-tracked configuration. First probe one small query for each required endpoint, record response codes, permissions and actual field names, then collect prices from at least 2018-01-01 and filings from at least 2012-01-01. Re-run the nine-node equivalence audit and check `DATA_PROVIDER_DRIFT_POLICY.json` before using Tushare data for 65 monthly snapshots. An endpoint returning rows does not by itself establish full coverage.

Until this happens, the Tushare branch of retrospective Phase 6–13 remains incomplete: adjusted-series equivalence, full universe/security state, corporate actions, 65/65 snapshots, consistency audit and first historical V1 replay have not been produced. The existing nine Baostock nodes and partial Eastmoney bars are retained as reference material. The public-data prospective protocol is independent; see `PUBLIC_V1_PROSPECTIVE_PROTOCOL.md`.
